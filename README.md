# iMarketplace

## 📖 Overview
iMarketplace is a modern online marketplace built to deliver a seamless and interactive shopping experience. It uses contemporary web technologies to provide a responsive, scalable, and user-friendly interface for browsing and managing products.

## 🚀 Features
- Product browsing and exploration experience
- Dedicated product showcase (including Apple products)
- Responsive design for all devices
- Modern UI with reusable components
- Fast and optimized client-side performance

## 🛠 Tech Stack

Frontend:
- React
- TypeScript
- Redux Toolkit
- React Redux
- React Router DOM
- Styled-Components
- Material UI (MUI)
- Emotion (React & Styled)
- Swiper.js
- React Select
- React Loader Spinner
- Country Flag Icons
- Grommet Icons

Other:
- Vite
- Sass / SCSS
- Redux Persist
- ESLint
- TypeScript ESLint
- Rollup Plugin Sass
- Rimraf
- Node.js / npm
